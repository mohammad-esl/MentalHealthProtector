# پروژه‌ها

برای هر موضوع چندمرحله‌ای یک پرونده از [_template.md](_template.md) بساز. هدف، زمینه، وابستگی‌ها و تصمیم‌ها در پروندهٔ پروژه می‌مانند.

فهرست تسک‌ها فقط در [TASKS.md](../TASKS.md) و قدم‌های اجرایی فقط در [STEPS.md](../STEPS.md) نگهداری می‌شوند. اشخاص و رابطه‌های مستند در [PEOPLE.md](../PEOPLE.md) قرار دارند. تسک‌ها را در پروندهٔ پروژه تکرار نکن.

پروندهٔ پروژه پس از پایان یا کنارگذاشتن آن به `ARCHIVE/` منتقل می‌شود؛ ردیف‌های تسک و تاریخچه پاک نمی‌شوند.
