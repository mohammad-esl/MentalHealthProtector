# همراه مدیریت کارها

این ریپو روش کاری Markdown محور برای همکاری با Agent دارد. کارها را در چت می‌گویی؛ Agent هر ابهام لازم را می‌پرسد، پاسخ را در جدول تسک‌ها ثبت می‌کند و به مرتب‌کردن و برنامه‌ریزی کمک می‌کند. لازم نیست فایل‌ها را باز یا دستی ویرایش کنی.

## شروع سریع

Codex یا Claude Code را در این ریپو باز کن و مثلاً در چت بنویس:

- «می‌خوام همهٔ کارهایی که ذهنم رو مشغول کرده خالی کنم.»
- «برای این کار چه چیزهایی رو باید بدونی تا اولویتش رو مشخص کنی؟»
- «برای امروز کمکم کن یک کار اصلی انتخاب کنم.»
- «این پروژه رو به قدم‌های کوچک و قابل انجام تقسیم کن: …»
- «این تسک تموم شد؛ فهرست و اولویت‌ها رو به‌روز کن.»

Agent اگر نتیجهٔ مطلوب، موعد واقعی، مانع، یا ظرفیتی که روی برنامه اثر دارد نامشخص باشد، خودش در چت سؤال می‌کند. تو جواب می‌دهی؛ Agent جدول و فایل‌های مربوط را اصلاح می‌کند.

## نمایشگر سادهٔ تسک‌ها

برنامهٔ [نمایش تسک‌ها](app/index.html) فایل [TASKS.md](TASKS.md) را می‌خواند و جست‌وجو، فیلتر و مرتب‌سازی بر اساس اولویت، موعد، وضعیت و پروژه دارد. داده فقط در همان جدول Markdown نگهداری می‌شود؛ UI فایل جداگانه‌ای برای نگهداری تسک‌ها ندارد.

برای اجرا، ترمینال را در پوشهٔ اصلی ریپو باز کن و سرور محلی Python را اجرا کن:

```powershell
py -m http.server 8081 --bind 127.0.0.1
```

بعد در مرورگر به `http://127.0.0.1:8081/app/` برو. این نمایشگر از HTML، CSS و JavaScript مرورگر استفاده می‌کند و کتابخانه یا بستهٔ جانبی ندارد. سرور را با `Ctrl+C` متوقف کن. اگر فرمان `py` در دسترس نبود، `python -m http.server 8081 --bind 127.0.0.1` را امتحان کن.

## چیدمان مسئولیت

تو با Agent در چت کار می‌کنی. Agent اطلاعات را می‌پرسد و ذخیره می‌کند. `TASKS.md` منبع واحد تسک‌هاست؛ برنامهٔ HTML همان جدول را برای دیدن و فیلترکردن می‌خواند. برای تغییر تسک از چت استفاده کن؛ فایل‌ها را دستی تغییر دادن لازم نیست.

این سیستم برای سبک‌کردن برنامه‌ریزی است و جای کمک حرفه‌ای سلامت روان را نمی‌گیرد.

Agent هنگام کار روی تسک‌ها خودش سرور محلی نمایشگر را روی `http://127.0.0.1:8081/` بررسی و در صورت نیاز اجرا می‌کند؛ لازم نیست تو فرمانی اجرا کنی. برای دیدن جدول در مرورگر، `http://127.0.0.1:8081/app/` را باز کن. اگر سرور خودکار بالا نیامد، آن را از ریشهٔ ریپو با `py -m http.server 8081 --bind 127.0.0.1` اجرا کن؛ در صورت نبودن `py` از `python -m http.server 8081 --bind 127.0.0.1` استفاده کن.
