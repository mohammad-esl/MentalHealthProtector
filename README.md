# همراه مدیریت کارها

این مخزن یک فضای کاری Markdown برای همکاری با Agent است. تو کارها را به زبان خودت مطرح می‌کنی؛ Agent آن‌ها را مرتب می‌کند، دربارهٔ اولویت‌ها با تو تصمیم می‌گیرد و قدم بعدی را ثبت می‌کند. لازم نیست خودت قالب یا نرم‌افزار مدیریت تسک نگه داری.

## شروع سریع

در Codex یا Claude Code این مخزن را باز کن و یکی از این درخواست‌ها را بنویس:

- «می‌خوام همهٔ کارهایی که ذهنم رو مشغول کرده خالی کنم.»
- «برای امروز کمکم کن یک کار اصلی انتخاب کنم.»
- «این پروژه رو به قدم‌های کوچک و قابل انجام تقسیم کن: …»
- «برنامه‌ام عوض شده؛ بیا اولویت‌ها رو دوباره بررسی کنیم.»

می‌توانی هر وقت خواستی یادداشت خام را در [INBOX.md](INBOX.md) بنویسی و از Agent بخواهی آن را بررسی کند. خود Agent هم می‌تواند متن گفت‌وگو را به فایل مناسب منتقل کند.

## شکل کار

1. **جمع‌آوری:** موارد خام را بگو یا در Inbox بنویس. Agent آن‌ها را دسته‌بندی می‌کند و فقط سؤال‌هایی را می‌پرسد که برای تصمیم لازم‌اند.
2. **انتخاب:** Agent موعد واقعی، پیامد عقب‌انداختن، وابستگی‌ها و ظرفیت فعلی را بررسی می‌کند و دلیل پیشنهادش را می‌گوید.
3. **ثبت:** کار تک‌مرحله‌ای در TASKS.md می‌ماند تا زمان مناسبش برسد؛ موضوع چندمرحله‌ای پروندهٔ پروژه می‌گیرد.
4. **شروع:** پس از توافق، تمرکز را در FOCUS.md ثبت می‌کند. آنجا یک کار اصلی و تا دو گزینهٔ بعدی جا می‌گیرد.
5. **پیگیری:** وقتی شرایط یا ظرفیت تغییر کرد، اولویت‌ها را دوباره بررسی و فایل‌ها را به‌روز کن.

کارهای بزرگ فقط به اندازه‌ای خرد می‌شوند که قدم بعدی روشن و شروع‌پذیر باشد. در هر گفت‌وگو لازم نیست همهٔ پروژه‌ها را مرور کنی. جزئیات قواعد در [WORKFLOW.md](WORKFLOW.md) است.

## حریم و اختیار

فایل‌ها اینجا داخل همین مخزن ذخیره می‌شوند. Agent می‌تواند آن‌ها را برای ثبت تصمیم‌های خودت ویرایش کند؛ اگر دربارهٔ اولویت یا موعد مطمئن نیست، پیشنهاد را از تصمیم قطعی جدا می‌کند. هیچ کار یا تعهدی را بی‌صدا حذف یا به‌عنوان موعد واقعی ثبت نمی‌کند.

این سیستم برای سبک‌کردن برنامه‌ریزی است و جای کمک حرفه‌ای سلامت روان را نمی‌گیرد.
