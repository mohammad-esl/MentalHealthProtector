# همراه مدیریت کارها

این ریپو سامانه‌ای فارسی برای ثبت و روشن‌کردن کارها در چت است. Agent اطلاعات را می‌پرسد، پروژهٔ بزرگ را به قدم‌های اتمیِ یک‌روزه تقسیم می‌کند، موعد و اولویت را بدون حدس ثبت می‌کند و تغییرات را در Markdown نگه می‌دارد.

## صفحه‌ها

از [نمایشگر](http://127.0.0.1:8081/app/) استفاده کن:

- [کارها](http://127.0.0.1:8081/app/) — تسک‌ها، موعدها، فیلتر و جست‌وجو.
- [قدم‌های روزانه](http://127.0.0.1:8081/app/steps.html) — کارهای اتمی، وابستگی‌ها و نشانهٔ پایان.
- [انجام‌شده‌ها و تاریخچه](http://127.0.0.1:8081/app/completed.html) — تسک‌های انجام‌شده و زمان ثبت رویدادها.
- [شبکهٔ افراد](http://127.0.0.1:8081/app/network.html) — افراد، پروژه‌ها و رابطه‌های مستند.

نمایشگر فقط‌خواندنی است؛ داده از فایل‌های Markdown می‌آید.

## اجرا

از ریشهٔ مخزن سرور محلی را اجرا کن:

```powershell
py -m http.server 8081 --bind 127.0.0.1
```

سپس `http://127.0.0.1:8081/app/` را باز کن. در صورت نبودن `py`، `python -m http.server 8081 --bind 127.0.0.1` را اجرا کن. Agent در نوبت‌های مدیریت تسک سرور را بررسی و در صورت نیاز خودش اجرا می‌کند.
