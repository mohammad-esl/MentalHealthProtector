# صف تصمیم

Agent اصلی فقط تصمیم‌های مؤثر و هنوز نامعلوم را ثبت می‌کند. «منتظر پاسخ»، «پاسخ‌داده‌شده» و «لغوشده» وضعیت تصمیم‌اند و وضعیت تسک را عوض نمی‌کنند. پاسخ نامعلوم «—» است؛ فرض، پیشنهاد Agent و سکوت کاربر تأیید محسوب نمی‌شوند. مورد پاسخ‌داده‌شده حفظ شود؛ پاسخ تازه با زمان/منشأ و سابقه در پروندهٔ مأموریت ثبت شود.

در سلول جدول از نویسهٔ جداکنندهٔ `|` استفاده نکن؛ گزینه‌ها را با «؛» جدا کن. شناسهٔ مأموریت و نسخه مشخص می‌کنند تصمیم به کدام قرارداد مربوط است. پاسخ‌های پیشین و لغوها حفظ می‌شوند.
