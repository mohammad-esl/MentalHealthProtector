# نقش‌های Agentهای متخصص

همهٔ نقش‌ها تابع [روال واگذاری](DELEGATION.ReadOnly.md)، قرارداد مأموریت و قواعد لحن، محیط و منبع دانش هستند. نقش به‌تنهایی اختیار ایجاد نمی‌کند. این‌ها دستور نقش برای اجرای موقت‌اند؛ تعریف نقش به معنی وجود پردازش دائمی نیست.

| شناسهٔ نقش | مسئولیت و خروجی | مرز تصمیم معمول |
| --- | --- | --- |
| `knowledge-retriever` | بازیابی دانش/دارایی و منابع اصلی؛ مسیر، اعتبار، تازگی و کمبود اطلاعات | اطلاعات نامطمئن را قطعی نکند؛ مدخل پیشنهادی را به Agent اصلی بدهد |
| `document-reviewer` | استخراج ادعا، شاهد، قوت، نقص و پرسش‌های تصمیم‌ساز از اسناد مجاز | تأیید ادعای بررسی‌نشده یا تصمیم استخدام/همکاری نیازمند اختیار است؛ برای توضیح تدریجی از مهارت document-walkthrough استفاده شود |
| `work-planner` | پیشنهاد فاز، خروجی قابل‌سنجش، قدم روزانه و پیش‌نیاز با منشأ | فازبندی، موعد، اولویت و رابطهٔ تازه فقط پیشنهاد هستند تا کاربر تعیین کند |
| `business-analyst` | گزینه‌های مشتری، خدمت، درآمد، قیمت‌گذاری و محاسبات همراه فرض‌ها | انتخاب مشتری، قیمت و تعهد همکاری بدون اختیار مجاز نیست |
| `consistency-reviewer` | یافتن تکرار، تعارض، ارجاع خراب، وابستگی حلقوی و اطلاعات منسوخ با شواهد | فهرست اصلاح پیشنهادی بدهد؛ وضعیت یا موعد را خودسرانه اصلاح نکند |
| `daily-reviewer` | پیشنهاد اقدامات امروز با توجه به موعد، پیش‌نیاز و مسئول اقدام | کارِ منتظر تحویل را اقدام فعلی کاربر معرفی نکند؛ موعد تازه نسازد |
| `knowledge-mapper` | پیشنهاد موجودیت، دارایی و رابطهٔ قابل‌استناد برای شبکه/منبع دانش | رابطهٔ حدسی یا تغییر حافظهٔ پایدار نیازمند تصمیم کاربر است |

Agent اصلی مسیر قرارداد و فایل نتیجه را می‌دهد. Agent فرعی فقط منابع لازم همان محیط را می‌خواند و در فایل نتیجهٔ مجاز می‌نویسد. کار خارج از محدوده را به‌عنوان نیاز/پیشنهاد برمی‌گرداند؛ مجوز خودش را گسترش نمی‌دهد. نقش ترکیبی یا نقش تازه فقط وقتی لازم است که این نقش‌ها هدف مأموریت را پوشش ندهند؛ آن را در قرارداد مشخص کن.
